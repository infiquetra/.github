[Infiquetra, LLC](https://www.infiquetra.com) is an Indiana parent holding company. [Infiquetra Software LLC](https://www.software.infiquetra.com) is its operating software studio.

## Projects

- [Talaria](https://github.com/infiquetra/talaria) — Rust terminal client for the Hermes agent gateway.
- [Mimir](https://github.com/infiquetra/mimir) — Rust desktop companion for EVE Online.
- [Infiquetra Agent Plugins](https://github.com/infiquetra/infiquetra-agent-plugins) — Agent workflow plugins and tooling, including portable skills and vendor adapters.
